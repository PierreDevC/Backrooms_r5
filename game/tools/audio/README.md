# Howler audio (r7.1)
`src/` holds 19 CC0 source clips from OpenGameArt and Freesound; authors and exact source pages are in `docs/CREDITS.md`. `build_howler_audio.js` (Node + Playwright, Chromium) layers, pitch-shifts, distorts and reverbs them offline with Web Audio and writes `game/src/howlerbank.js` (32 kHz mono PCM16 WAV, base64): `hcall0-2` (territorial calls) and `hsee0-2` (chase screams). The generated bank extends ABANK immediately after audiobank.js in build order.
Run: `CHROMIUM=/path/to/chromium NODE_PATH=/path/to/node_modules node game/tools/audio/build_howler_audio.js` then `python3 game/build.py`.
Calls last 5.6–6.4 s, screams 3.2–3.6 s, with 0.95 peak normalisation and a 0.25 s end fade. In-game gain, panning, distance and wall filtering are separate. Calls recur every 120–180 s per wandering Howler; busy entities defer them. Chase entry has a seven-second scream cooldown. Both follow the creature and stop on checkpoint relocation/scene teardown. Missing samples retain a procedural howl fallback.

`python3 game/tools/build_release_media.py` creates the six-clip standalone `audio_preview/Howler_r7_1.html` and embeds the saved Level 0 QA capture in the briefing image bank; run after the main Howler QA capture exists, before rebuilding the HTML. Open the preview at low volume. Automated decoding/positional tests do not establish subjective audio quality; human headphone review remains pending.
