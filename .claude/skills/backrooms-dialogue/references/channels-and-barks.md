# Branching, Barks & Radio Patterns

Use in step 2 (channel) and while drafting. Channels are listed as the game uses them in the spec. If a scene needs a channel that isn't listed, ask before inventing one.

## Channels

| Channel | Length | Texture and rules |
|---|---|---|
| M.E.G. radio (Level 0 survivor calls, Level 9 arrival warning, Level 5 and Level 18 radio) | One or two lines, usually under 12 words each | The speaker is somewhere else doing something else. Clipped, practical, cut by static. They never hear the player perfectly and rarely have time to repeat. |
| Explorer voices (Marsh, Okafor, Reyes, Brandt) | Short bursts | They talk to each other more than to the player and react to threats, supplies and each other. Explorers can die mid-run, so a line shouldn't depend on another explorer being alive unless the trigger guarantees it. |
| Lost tapes (Level 0) | Longer, up to about 40 words | Recorded before the player arrived, by someone who didn't know how it ends. False starts, handling noise, mistakes, corrections. A code digit arrives as an aside, not a reveal. If digits are randomized per run, check how the existing tapes voice them before writing. |
| Mimic | Mirrors the copied explorer | Borrowed voice, almost right. Reuse the real explorer's phrasing with one wrong detail: an exact repeat, the wrong name, too calm, wrong timing or direction. Never a villain speech. |
| Whispers and hallucinations (Level 5 phantom whispers, Level 18 regret whispers) | Fragments of a few words | Second person, ordinary domestic details, no metaphors. Never a full explanatory sentence. |
| Notes, signs and kiosk text (front-desk note, lockers, signage) | As long as the writer needed | Written by someone with a job, in their jargon. The useful information is there because they needed it, not because the player does. |
| Briefing slides and UI | Plain and instructional | Not in character. This is the one place mechanics get spelled out. |
| Death, retry and ending text | A few words | Camcorder register: terse, timestamped, no commentary. |

## Barks

- **Purpose first.** Each bark set communicates one game state: heard something, spotted light, lost the target, hurt. Write the state in the notes column.
- **Volume.** Write 8 to 12 variants and keep the best 4 to 6. No two should start with the same word.
- **Tiers.** Idle, suspicious, alert, lost. Each tier differs in length and rhythm, not only in wording.
- **Signal the effect, not the mechanic.** React to what the player caused ("Who turned the lights off?") instead of naming the system behind it.
- **Non-verbal entities stay non-verbal.** Howlers, Wretches, Deathmoths and the Watch communicate through sound design unless the spec says otherwise. Write cue notes for audio, not words.

## Pacing in horror

- **Silence counts.** Space radio calls out. Don't fill every walk.
- **Information before the threat, not during it.** In a chase, speakers get one to three words.
- **The tension ladder:** rumor (radio, tape), then sign (a note, a sound), then glimpse, then encounter. Dialogue mostly lives on the first two rungs.
- **Let some lines go unheard.** A call can be cut off by distance, static or the player walking away. Never put must-know information only in a line the player can miss; back it up with objective text.

## If dialogue choices are ever added

The spec doesn't show dialogue choices today. If they arrive, use Jon Ingold's pattern:

- Offer three options: **Accept** (go along, answer the question), **Reject** (push back, end the small talk) and **Deflect** (change the subject without breaking tone).
- **Loops** hold a conversation at the same intensity. **Trapdoors** let the player skip ahead. Both characterize the speaker: someone who throws you back into the loop for challenging them is defined by that structure.
- No filler options like "Tell me more" or "What do you think?". Every option should be something the player character would plausibly say.
